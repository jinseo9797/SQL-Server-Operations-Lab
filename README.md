# SQL Server Operations Lab

## 프로젝트 목적

기존 데이터베이스를 인수인계받는 상황을 가정하여 SQL Server의 운영 및 관리 역량을 기르기 위한 개인 실습 프로젝트입니다.

시스템 카탈로그 뷰와 DMV를 활용하여 데이터베이스의 구조와 운영 상태를 파악하고, 성능 저하 및 장애 상황에 대한 원인 분석과 해결 과정을 기록합니다.

## 실습 환경

- SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- WideWorldImporters (Microsoft 공식 샘플 데이터베이스)

## 진행 방식

업무 요구사항을 바탕으로 필요한 시스템 뷰와 컬럼을 확인하고 직접 SQL을 작성합니다. 학습 과정에서 AI의 개념 설명과 코드 리뷰를 활용합니다.

## 진행 현황

- [x] 실습 환경 구축 및 데이터베이스 복원

- [ ] 데이터베이스 모니터링
- [ ] 쿼리 성능 분석 및 개선
- [ ] Blocking 장애 대응
- [ ] 데이터 오류 및 보정
- [ ] 백업 및 특정 시점 복구
- [ ] 운영 업무 자동화
